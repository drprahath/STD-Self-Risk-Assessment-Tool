│                      WHAT IF SOMETHING GOES WRONG?                           │
└──────────────────────────────────────────────────────────────────────────────┘

Error: "Module not found"
→ Update requirements.txt with missing package
→ Push to GitHub
→ Streamlit auto-redeploys

Error: "File not found"  
→ Ensure all 5 files in repository root
→ Check file names (case-sensitive)
→ Verify .gitignore doesn't exclude needed files

Error: "App won't start"
→ Check Streamlit Cloud logs
→ Look for Python errors
→ Verify main file is: std_risk_assessment_app.py

Error: "403 Forbidden"
→ Repository must be PUBLIC
→ Change repository settings to public
→ Redeploy
